# Game Filter

Мой учебный проект на React — каталог игр с поиском, фильтрами и избранным.

[Открыть сайт](https://mrmeuzi.github.io/Game_Filter/)

## Что можно делать

- Искать игры по названию.
- Фильтровать каталог по жанрам, платформам, тегам, режимам игры, рейтингу и периоду выхода.
- Сортировать игры по рейтингу и дате выхода.
- Переключать страницы каталога и вручную вводить номер страницы.
- Открывать страницу игры с описанием, рейтингом, разработчиком, видео и скриншотами.
- Просматривать скриншоты в увеличенном виде на компьютере.
- Добавлять игры в избранное и удалять их оттуда.

В избранном есть свой поиск, фильтры по рейтингу, точному году выхода, жанрам, платформам и тегам. Также можно сортировать игры по алфавиту, рейтингу и дате. Избранное сохраняется в localStorage и остаётся после перезагрузки страницы.

В списках фильтров одновременно видно до десяти пунктов, остальные доступны при прокрутке. Есть поиск по названиям фильтров.

## Откуда берутся данные

Сайт использует [GameBrain API](https://gamebrain.co/api). Запросы проходят через Cloudflare Worker:

```text
Браузер → Cloudflare Worker → GameBrain API
```

Ключ API хранится в секрете `GAMEBRAIN_API_KEY` на стороне Worker и не попадает в код сайта. Ответы кешируются до 24 часов в Worker и в браузере. Повторные одинаковые запросы используют кеш, чтобы экономить лимит API.

Если запрос не удался или лимит исчерпан, сайт показывает сообщение об ошибке и кнопку повтора.

API позволяет запрашивать результаты со смещением до 1000 записей. Поэтому каталог показывает до 51 страницы по 20 игр — первые 1020 результатов. Для более точной выборки нужно использовать поиск и фильтры. Точный год и сортировка по алфавиту доступны в избранном.

Игры, сохранённые во время работы с RAWG, остаются в избранном. На их странице можно перейти к поиску по названию в новом каталоге и добавить найденную игру заново.

## Что использовал

- React и JavaScript.
- React Router с HashRouter для переходов между страницами на GitHub Pages.
- React hooks и localStorage для работы с избранным.
- HTML и CSS, адаптивная вёрстка.
- GameBrain API и Cloudflare Workers.
- Jest и React Testing Library для тестов.
- GitHub Pages для размещения сайта.
