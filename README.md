# Game Filter

Это мой учебный проект, который я сделал во время изучения React.

Сайт представляет собой каталог компьютерных игр. Данные об играх загружаются из GameBrain API.

В проекте я научился получать данные с внешнего API, выводить их на странице и разбивать интерфейс на отдельные React-компоненты. Также я работал с состоянием, хуками, маршрутизацией и передачей данных между компонентами.

На сайте можно:

- посмотреть список игр;
- найти игру по названию;
- отфильтровать игры по жанру, платформе, рейтингу, тегам и периоду выхода;
- переключаться между страницами каталога;
- открыть отдельную страницу игры и посмотреть подробную информацию;
- добавить игру в избранное или удалить её оттуда.

Для избранного я использовал Context API, а для переходов между страницами — React Router. Также добавил отображение загрузки и обработку ошибок при получении данных.

В проекте использовал:

- React;
- JavaScript;
- React Router;
- Context API;
- GameBrain API;
- HTML;
- CSS;

## Запуск

Установить зависимости: npm ci. Запустить локально: npm start. Проверить тесты: npm test -- --watchAll=false. Собрать сайт: npm run build.

Запросы к GameBrain проходят через Cloudflare Worker https://game-filter-api.mrmeuzi56.workers.dev. Ключ хранится в секрете GAMEBRAIN_API_KEY на стороне Worker и не входит в сборку сайта. Ответы кешируются до 24 часов.

Каталог использует доступные GameBrain сортировки по рейтингу и дате. API разрешает смещение до 1000 записей; пагинация ограничена 51 страницей. Сортировка по алфавиту и выбор точного года доступны в избранном. Сохранённые игры RAWG остаются в избранном; на их странице есть поиск по названию в новом каталоге.
